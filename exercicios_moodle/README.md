# Exercícios do Moodle

Organize uma pasta por atividade: `atividade_01`, `atividade_02` etc. Dentro dela, guarde seus arquivos `.c`, eventuais `.h` e anotações de testes.

Antes de entregar:

1. Confira o nome do arquivo e o padrão de C exigidos no enunciado.
2. Respeite exatamente a entrada e a saída solicitadas; não adicione mensagens como "Digite um número" quando o avaliador não as pedir.
3. Compile e teste os exemplos e casos de borda.
4. Envie os arquivos solicitados pelo Moodle/VPL dentro do prazo.
5. Faça commit e push para manter uma cópia no GitHub.

O repositório é público. Siga as regras da disciplina sobre divulgação de soluções e não inclua credenciais, notas ou dados de outras pessoas. O GitHub guarda o histórico; não efetua a entrega no Moodle.
