# Aulas práticas

- [conteudo_teorico](conteudo_teorico/README.md): transcrições em Markdown dos PDFs das práticas, com páginas de referência e complementos identificados.
- [exercicios_aulas_praticas](exercicios_aulas_praticas/README.md): programas escritos pelo aluno, organizados por aula.
- As demonstrações dos slides ficam em [aulas_exemplos](../aulas_exemplos/README.md), separadas das suas soluções.

A [prática 01](conteudo_teorico/01_linguagem_c.md) apresenta edição, compilação, execução e comandos do terminal Linux. O exemplo de referência está em [aula_pratica_01](../aulas_exemplos/aula_pratica_01/README.md).

Cada exercício independente pode ter seu próprio `main`; compile um de cada vez. As tarefas do VS Code funcionam com o arquivo `.c` ativo, independentemente da pasta. Fazer push no GitHub não substitui a entrega no Moodle.
