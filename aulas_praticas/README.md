# Aulas práticas

Crie uma pasta por aula, como `aula_01`, e um arquivo por exercício independente, como `exercicio_01.c`. Cada programa pode ter seu próprio `main`; compile um de cada vez.

A pasta `aula_01` já contém `ola_mundo.c` para conferir o ambiente. Abra esse arquivo e execute a tarefa **C: compilar e executar arquivo ativo** no VS Code.

Salve enunciados próprios e anotações em Markdown junto aos códigos. Registre entradas, saídas esperadas e dúvidas. A publicação no GitHub não substitui a entrega exigida no Moodle.
