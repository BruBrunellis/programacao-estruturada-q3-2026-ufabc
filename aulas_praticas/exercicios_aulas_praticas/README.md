# Exercícios feitos pelo aluno

Guarde aqui seus programas das aulas práticas, separados por aula:

```text
exercicios_aulas_praticas/
└── aula_01/
    ├── README.md
    └── exercicio_01.c   # Crie este arquivo ao iniciar sua solução
```

Um arquivo `.c` por exercício independente, com seu próprio `main`. Anote entradas, saídas esperadas e dúvidas no README da aula. Os enunciados e prazos devem ser consultados no Moodle; o PDF da prática 01 não contém uma lista de exercícios a resolver.

Consulte as demonstrações em [aulas_exemplos](../../aulas_exemplos/README.md). Esta pasta está reservada às suas tentativas; nenhuma solução de exercício foi criada nesta atualização.
