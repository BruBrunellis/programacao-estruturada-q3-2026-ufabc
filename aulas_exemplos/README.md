# Exemplos das aulas

Demonstrações apresentadas nos PDFs das aulas teóricas e práticas. Cada subpasta identifica a origem; cada programa é compilado separadamente.

| Aula | Conteúdo disponível | Origem |
| --- | --- | --- |
| [Teórica 01](aula_teorica_01/README.md) | `ola_mundo.c`, exemplo introdutório já existente, preservado na reorganização | `01_TEORIA.pdf`, p. 11–12; mensagem adaptada ao repositório |
| [Prática 01](aula_pratica_01/README.md) | `paridade.c`, classifica os números de 1 até N | `01_PRATICA.pdf`, p. 6 e 12 |

A pasta teórica contém, por enquanto, apenas o exemplo introdutório; os demais exemplos do PDF teórico ainda não foram transcritos para arquivos `.c`.

Abra o `.c`, salve e selecione **C: compilar e executar arquivo ativo** no VS Code. Use `F5` para depurar. As soluções produzidas pelo aluno ficam em [exercicios_aulas_praticas](../aulas_praticas/exercicios_aulas_praticas/README.md).
