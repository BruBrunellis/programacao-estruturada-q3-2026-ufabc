# Exercícios livres

Espaço para exercícios de treino, inclusive os solicitados ao Codex.

Sugestão de organização: `tema/nome_do_exercicio/`, com `README.md` para o enunciado e os casos de teste, e `solucao.c` para sua tentativa.

Exemplo de pedido: "Crie cinco exercícios progressivos sobre condicionais em C, com enunciados e entradas/saídas de exemplo, sem fornecer as soluções."

Registre o que tentou e as dúvidas antes de pedir uma correção. Nenhuma lista adicional foi criada nesta preparação.
